# Nexora

Landing Page responsiva desenvolvida com HTML5 e CSS3.

## Tecnologias

- HTML5
- CSS3

## Conceitos praticados

- HTML semântico
- Flexbox
- CSS Grid
- Responsividade
- Interações e transições com CSS

## ## Como executar

1. Baixe o projeto ou clone o repositório do GitHub.
2. Abra a pasta `frontend-01-nexora`.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em um navegador, como o Google Chrome, para visualizar a Landing Page.

**Dica:** Para visualizar ou modificar o código-fonte, abra a pasta do projeto no Visual Studio Code (VS Code).
